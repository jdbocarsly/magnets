# Historical project material

- `notes/`: the original migration plan, todo list and deployment notes.
- `web/`: unused old templates and styles; active website sources are in
  `web/` at the repository root.
- `dos/`: old notebook and plot experiments formerly mixed into DOS inputs.
- `local/`: ignored raw calculations, old server logs, editor files, backups
  and the former `stuff/` experiments. Files were moved here, not deleted.

These files are not used by the site builder or included in the published
`docs/` folder. Previously untracked research files remain untracked unless
explicitly added; the `local/` archive stays ignored.
